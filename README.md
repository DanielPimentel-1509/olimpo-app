# OLIMPO

App de entrenamiento personal de Daniel Pimentel. PWA autocontenida (un solo
`index.html` con CSS/JS inline, sin build), instalable, funciona offline,
guarda datos en localStorage.

Producción: https://olimpo.netlify.app

## Deploy

Netlify, sin build command, publish directory = raíz del repo. Cada push a
`main` se despliega automáticamente.
